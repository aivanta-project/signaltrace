# Security Policy

## Supported Versions

SignalTrace is currently in **Research and Development**. Formal security support commitments and patch releases will begin alongside version `v1.0.0`.

| Version | Supported |
| :--- | :--- |
| R&D / 0.1.x | Experimental / Best-effort |

## Reporting a Vulnerability

Security and cryptographic soundness are central to SignalTrace's mission. If you discover a vulnerability, cryptographic weakness, or implementation defect, please report it privately:

- **Email:** `security@aivanta.org` or contact project maintainers via [GitHub Security Advisories](https://github.com/aivanta-project/signaltrace/security/advisories).
- Please do not submit public issues or PRs containing vulnerability details until the issue has been triaged and a disclosure plan is agreed upon.

### Report Content

Please include:
1. Description of the vulnerability or flaw (e.g., hash collision risk, replay attack, trace truncation).
2. Steps to reproduce or proof-of-concept (PoC).
3. Potential impact on execution trace verifiability.

We acknowledge receipt of reports within 48 hours and coordinate fixes in accordance with responsible disclosure principles.
